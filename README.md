# AI-Job-Market-Skill-Demand-Intelligence
End-to-end AI job market and skill demand analytics project using Python, SQL, Power BI, DAX and Excel.

📊 Power BI Dashboard

The project contains 7 interactive dashboard pages:

1. Main Page

Provides an overall view of the AI & Data job market using key KPIs and high-level analytics.

2. Skill Intelligence

Analyzes technical skill demand and identifies the skills most frequently required by employers.

3. Salary Intelligence

Analyzes salary patterns across experience levels, roles, and other job-market dimensions.

4. Company Insights

Provides insights into companies, job opportunities, and hiring patterns.

5. Location Insights

Analyzes the geographical distribution of AI & Data job opportunities.

6. Reports

Provides detailed analytical reports covering:

Jobs by Years of Experience
Top Job Roles by Job Count
Top Skills by Job Count
Jobs by Experience Level
Jobs by Industry
Average Salary by Experience Level
7. Insights & Recommendations

Summarizes the major market findings and provides practical recommendations for students, job seekers, recruiters, and educational institutions.

🧹 Data Cleaning & Preparation

Python was used to prepare the dataset before performing analysis.

The major data-cleaning steps included:

Checking and removing duplicate records
Handling missing values
Converting data types
Standardizing categorical values
Validating salary data
Validating years of experience
Creating useful analytical columns
Performing data-quality checks

The cleaned dataset was then used for SQL analysis and Power BI reporting.

🗄️ SQL Analysis

SQL was used to perform structured analysis on the cleaned job-market dataset.

Key analysis included:

Total number of jobs
Number of unique companies
Most demanded job roles
Job distribution by location
Job distribution by industry
Average salary by experience level
Most frequently required skills
Relationships between roles, skills, experience, and salary
🧮 DAX Analysis

DAX measures were created in Power BI to calculate important business metrics.

Examples include:

These measures allow the dashboard to dynamically respond to filters and user selections.

💡 Key Insights

The analysis provides several important insights into the AI & Data job market:

Data Analyst and Data Scientist roles show strong demand in the analyzed market.
Python and SQL are among the most frequently required technical skills.
Machine Learning and cloud technologies are important skills across AI & Data roles.
Salary generally increases with professional experience.
Senior and Lead-level positions tend to have higher compensation.
Bangalore, Hyderabad, and Pune are important locations for AI & Data opportunities in the analyzed dataset.
